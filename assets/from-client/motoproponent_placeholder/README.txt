MOTOPROPONENT — PLACEHOLDER WEBSITE
====================================

CONTENTS
--------
index.html
assets/background.jpg       Background photo (your first image)
assets/youtube-photo.jpg    YouTube link photo (your second image)
assets/instagram-photo.webp Instagram link photo (your third image)

DEPLOYMENT
----------
1. Extract the ZIP file.
2. Upload the contents of the "motoproponent_placeholder" folder to the
   website's document root (often named public_html, www, or htdocs).
3. Make sure index.html is in that document root, not one folder deeper.
4. Visit the domain and refresh the page.

This is a static website. It requires no database, build process, server-side
runtime, or external libraries. The social cards open the supplied YouTube
and Instagram URLs in a new tab.

CUSTOMIZATION
-------------
Edit index.html to change the heading, tagline, or social links.
Replace the images in assets/ to change the photos, keeping the same filenames.
